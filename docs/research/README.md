## Исследование новой страны

Новые исследования создаются только по [единому стандарту](../COUNTRY_RESEARCH_STANDARD.md) и проверяются по [Research Package 3.0](../../data/research-package-v3.0.schema.json).

Для запуска исследования используйте [готовый промпт](../NEW_COUNTRY_RESEARCH_PROMPT.md). Отдельный каталог параллельных или старых версий внутри репозитория не создаётся: до принятия исследования его файлы хранятся вне рабочего проекта, а после проверки добавляется только текущая версия.

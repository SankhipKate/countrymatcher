## Блокеры публикации

1. Investor Pass должен оставаться `publishable: false`, пока анкета не собирает инвестиционные данные.
2. Иностранный однополый брак или партнёрство нельзя использовать как подтверждённое семейное основание.
3. Для постоянной резиденции нельзя подставлять числовой минимум дохода: официальное правило основано на документальных категориях.
4. Нельзя обещать сохранение российского гражданства после натурализации.

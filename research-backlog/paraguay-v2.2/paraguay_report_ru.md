# Парагвай — исследование для Immigration Matcher

**Версия:** 2.2
**Дата проверки:** 2026-07-23
**Статус:** SECONDARY_REVIEW
**Уверенность:** MEDIUM

## Главный вывод

Общая временная резиденция с переходом к постоянной; отдельный Investor Pass для крупных инвестиций.

Юридическая доступность маршрута отделена от практической оценки города. Городские суммы не являются визовыми порогами.

## Маршруты

### Общая временная резиденция

До двух лет; для работы, бизнеса, учёбы и иных законных целей.

- **Первый срок:** 24 месяцев.
- **Доход/основание:** EMPLOYEE — Универсальный доходный порог для временной резиденции не подтверждён.; FREELANCE — Удалённая работа возможна; документы для ПМЖ оцениваются позже.; SELF_EMPLOYED — Подтверждение законной деятельности.
- **ПМЖ:** Обычно переход после временной резиденции сроком до 2 лет..
- **Гражданство:** Минимум 3 года проживания, профессия/деятельность и хорошая репутация..

### Постоянная резиденция после временной

Переход при подтверждении дохода/средств по категории.

- **Первый срок:** зависит от категории / сразу постоянный статус месяцев.
- **Доход/основание:** EMPLOYEE — Реальная занятость и доход по категории Resolución 407/2026.; FREELANCE — Документы удалённого работника/номада.; SELF_EMPLOYED — Реальная деятельность и доходы.; PENSION — Документы пенсионера/иждивенца.
- **ПМЖ:** Это уже постоянная резиденция..
- **Гражданство:** Минимум 3 года проживания, деятельность в стране и хорошая репутация..

### Прямая постоянная резиденция инвестора

Без предварительной временной резиденции при инвестиции.

- **Первый срок:** зависит от категории / сразу постоянный статус месяцев.
- **Доход/основание:** INVESTMENT: 150 000 USD — USD 150 000 туризм или USD 200 000 недвижимость/ценные бумаги.
- **ПМЖ:** Прямая постоянная резиденция..
- **Гражданство:** Минимум 3 года; инвестиция не отменяет требования фактической связи..


## Семья и ЛГТБ

## Города

- **Асунсьон**: 950 USD для одного, 1500 USD для пары, 2050 USD для семьи с ребёнком; школа не включена.
- **Сьюдад-дель-Эсте**: 710 USD для одного, 1200 USD для пары, 1700 USD для семьи с ребёнком; школа не включена.
- **Энкарнасьон**: 680 USD для одного, 1100 USD для пары, 1550 USD для семьи с ребёнком; школа не включена.

## Открытые вопросы

- **HIGH — minimum_income_main_applicant**: Нет единого числового порога для 12 категорий. Получить полный Anexo.
- **CRITICAL — same_sex_family_reunification**: Однополый брак не признаётся; альтернатива не подтверждена.
- **HIGH — restricted_breeds**: Применимость списка пород ко въезду не подтверждена.
- **MEDIUM — estimated_monthly_cost**: Суммы основаны на вторичных агрегаторах.

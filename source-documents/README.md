# Документы Country Matcher

В проекте действуют только два нормативных документа:

1. [`COUNTRY_RESEARCH_STANDARD.md`](COUNTRY_RESEARCH_STANDARD.md) — что и как исследовать для каждой страны.
2. [`MATCHING_AND_RESULT_STANDARD.md`](MATCHING_AND_RESULT_STANDARD.md) — как сопоставлять исследованные правила с ответами анкеты и что показывать пользователю в браузере.

Остальные файлы в этой папке не устанавливают конкурирующие правила:

- `PROJECT_OVERVIEW.md` — простое описание продукта;
- `QUESTIONNAIRE_AND_RESULTS.md` — человекочитаемая карта вопросов анкеты;
- `ROADMAP.md` — будущие задачи;
- `NEW_COUNTRY_RESEARCH_PROMPT.md` — готовое задание для исследования новой страны; оно прямо ссылается на два нормативных документа выше;
- `COUNTRY_RESEARCH_ORDER.json` и `ОЧЕРЕДЬ_ИССЛЕДОВАНИЙ_СТРАН.xlsx` — очередь и статус исследований.

Если пояснительный файл расходится с одним из двух стандартов, исправляется пояснительный файл. Новые правила нельзя добавлять в README, отчёты стран или промпт в обход двух нормативных документов.

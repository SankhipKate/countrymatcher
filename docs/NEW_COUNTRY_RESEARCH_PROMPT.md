# Country Matcher — промпт для исследования новой страны

Этот файл не является третьим нормативным стандартом. Он содержит только готовое задание для ChatGPT. Единственные правила исследования и пользовательского результата находятся в двух документах:

- [стандарт исследования страны](https://raw.githubusercontent.com/SankhipKate/immigration-country-matcher/main/docs/COUNTRY_RESEARCH_STANDARD.md);
- [стандарт сопоставления и результата](https://raw.githubusercontent.com/SankhipKate/immigration-country-matcher/main/docs/MATCHING_AND_RESULT_STANDARD.md).

Структура итогового JSON определяется [Research Package 3.0 Schema](https://raw.githubusercontent.com/SankhipKate/immigration-country-matcher/main/data/research-package-v3.0.schema.json).

## Как использовать

1. Замените `[СТРАНА]` и `[КОД ISO]` в тексте ниже.
2. Отправьте весь текст промпта в новый чат ChatGPT с доступом к интернету и возможностью создавать файлы.
3. Не добавляйте старые отчёты других стран: исследование должно опираться на документы по ссылкам и актуальные источники.
4. Полученный пакет сначала проверяется отдельно. Он не заменяет файлы рабочего проекта до проверки полноты, схемы и источников.

## Готовый промпт

```text
Проведи полное исследование страны [СТРАНА] (ISO-код: [КОД ISO]) для проекта Country Matcher.

Перед началом полностью прочитай:
1. https://raw.githubusercontent.com/SankhipKate/immigration-country-matcher/main/docs/COUNTRY_RESEARCH_STANDARD.md
2. https://raw.githubusercontent.com/SankhipKate/immigration-country-matcher/main/docs/MATCHING_AND_RESULT_STANDARD.md
3. https://raw.githubusercontent.com/SankhipKate/immigration-country-matcher/main/data/research-package-v3.0.schema.json

Первый документ является единственным нормативным источником о том, что и как исследовать. Второй документ нужен, чтобы правильно заполнить структурированные данные, которые позднее использует движок и показывает браузер. Не придумывай новые статусы, вопросы анкеты или правила оценки пользователя.

Исследуй действующее на дату проверки законодательство и практические данные для гражданина Российской Федерации. Используй интернет и отдавай приоритет законам, официальным государственным и консульским источникам. Не подменяй неизвестное предположением. Не используй законопроекты, политические обещания или будущие планы как действующее правило.

Обязательно проверь все категории миграционных маршрутов, перечисленные в стандарте, включая международную защиту. Для каждой категории установи: маршрут существует; отсутствует; недоступен гражданам РФ; либо пока недостаточно данных для публикации. Не ограничивай исследование заранее выбранными популярными маршрутами.

Сохраняй официальные денежные суммы и валюты. Не записывай вручную фиксированные эквиваленты в USD. Разделяй требования, которые проверяются по анкете, условия, которые пользователь должен выполнить позднее, обычные документы и неизвестные факты.

Для места подачи проверь Россию, страну назначения и допустимые третьи страны. Если основные варианты недоступны, постарайся подтвердить хотя бы одну практически достижимую для пользователя третью страну, предпочтительно недалеко от страны его нахождения. Не скрывай маршрут только из-за того, что место подачи пока исследовано не полностью.

Для городов, климата, семей, школ, животных и ЛГБТ-раздела соблюдай точный обязательный состав и методику стандарта. Для животных исследуй только ограничения на ввоз собак и кошек, запреты отдельных пород и региональные запреты. Для ЛГБТ-раздела отдельно исследуй правовое положение и практическую среду; не используй общую преступность или отдельные происшествия как показатель.

Результат подготовь на русском языке в отдельных файлах:
- [код-страны]-research-v3.0.json — полный Research Package, проходящий предоставленную JSON Schema;
- [код-страны]-sources-v3.0.md — реестр источников с URL и датами проверки;
- [код-страны]-report-ru-v3.0.md — понятный исследовательский отчёт;
- [код-страны]-open-questions-v3.0.md — только действительно неразрешённые вопросы;
- [код-страны]-completeness-report-v3.0.md — проверка каждого обязательного раздела стандарта;
- [код-страны]-research-log-v3.0.md — дата, ход исследования и принятые решения;
- [код-страны]-test-profiles-v3.0.json — сценарии для последующей проверки адаптера и движка.

Перед выдачей результата самостоятельно проверь:
- JSON синтаксически корректен;
- JSON соответствует Research Package 3.0 Schema;
- все source_id существуют в реестре источников;
- у каждого публикуемого маршрута есть структурированные требования;
- числовые пороги имеют сумму, валюту, период, семейную формулу и источник;
- неизвестные данные явно обозначены и не превращены в положительный вывод;
- будущие изменения отделены от действующего права;
- все обязательные категории городов и оба температурных диапазона заполнены;
- отчёт, JSON и список открытых вопросов не противоречат друг другу.

Если ссылка недоступна или содержание любого обязательного документа не удалось прочитать полностью, остановись и прямо сообщи об этом. Не начинай исследование по памяти или по собственной альтернативной методике.
```

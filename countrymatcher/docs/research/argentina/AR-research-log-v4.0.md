# Аргентина — research log RP4

- 2026-08-10: старый v3-пакет использован только как seed для списка маршрутов и прежних источников.
- Полностью сверены действующие Final Lock schema и validator.
- Перепроверены основные миграционные маршруты по DNM/законам после реформы DNU 366/2025.
- Финансовый порог rentista/pensionado пересчитан только из официальных компонентов: 5 × действующий SMVM ARS 376 600 = ARS 1 883 000/мес.
- Разделены work rights: временные резиденты имеют общее право работать; DNV ограничен удалённой зарубежной деятельностью.
- Долгосрочная цепочка обновлена: non-MERCOSUR PR 3 года с присутствием; гражданство — 2 года непрерывного законного проживания без выездов.
- Добавлены гуманитарный и международная защита как отдельные исследованные маршруты.
- Инвестор оставлен скрытым из-за отсутствия подтверждённой актуальной операционной процедуры.
- Для всех четырёх отображаемых городов добавлена одинаковая прямая cost-корзина (аренда 85 м² в обычном районе + коммунальные услуги + месячный транспорт); низкая выборка Мендосы/Ушуайи отражена через confidence, а не через выдуманные значения.
- Национальный LGBT-блок перепроверен по актуальным правозащитным источникам; отсутствие методологичного city ranking зафиксировано как валидный `friendly_cities=[]`, а не open item.
- Для цифрового кочевника выявлен и закрыт реальный generic-engine blocker: `NO_FIXED_THRESHOLD` теперь проверяет допустимый тип и зарубежную географию текущего дохода без выдуманного денежного порога.

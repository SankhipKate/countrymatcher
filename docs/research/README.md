## Совместимость

Испания и Уругвай пока хранятся в формате 2.2 и используются действующим калькулятором. Формат 3.0 является стандартом для новых исследований. Подключение пакета Аргентины к движку выполняется отдельным этапом после добавления адаптера версии 3.0.

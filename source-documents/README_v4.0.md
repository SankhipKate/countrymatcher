# Документы Country Matcher

**Версия:** 4.0

В проекте действуют только два нормативных документа:

1. [`COUNTRY_RESEARCH_STANDARD_v4.0.md`](../source-documents/COUNTRY_RESEARCH_STANDARD_v4.0.md) — что и как исследовать для каждой страны.
2. [`MATCHING_AND_RESULT_STANDARD_v4.0.md`](../source-documents/MATCHING_AND_RESULT_STANDARD_v4.0.md) — как сопоставлять исследованные правила с ответами анкеты и что показывать пользователю в браузере.

Остальные файлы в этой папке не устанавливают конкурирующие правила:

- `PROJECT_OVERVIEW_v4.0.md` — простое описание продукта;
- `QUESTIONNAIRE_AND_RESULTS_v4.0.md` — человекочитаемая карта вопросов анкеты;
- `ROADMAP_v4.0.md` — будущие задачи;
- `NEW_COUNTRY_RESEARCH_PROMPT_v4.0.md` — готовое задание для исследования новой страны; оно прямо ссылается на два нормативных документа выше;
- `COUNTRY_RESEARCH_ORDER_v4.0.json` и `ОЧЕРЕДЬ_ИССЛЕДОВАНИЙ_СТРАН.xlsx` — очередь и статус исследований.

Если пояснительный файл расходится с одним из двух стандартов, исправляется пояснительный файл. Новые правила нельзя добавлять в README, отчёты стран или промпт в обход двух нормативных документов.


Final Lock 4.0: рабочие Research Package должны содержать `canon_revision = 2026-08-08-final-lock`; более ранние draft 4.0 пересобираются.

Политика конфиденциальности Country Matcher

2. Какие данные обрабатываются

2.1. Ответы анкеты

Анкета может содержать сведения о стране нахождения и статусе проживания, составе семьи, возрасте, доходах и сбережениях, долгосрочных целях, домашних животных, а также выборе учитывать права и признание ЛГБТ.

В текущей версии Country Matcher ответы анкеты и сохранённый черновик обрабатываются в браузере пользователя. Они сохраняются в localStorage устройства. Country Matcher не отправляет содержание ответов анкеты на собственный сервер для выполнения расчёта.

Пользователь может удалить сохранённые ответы через функцию очистки анкеты либо средствами браузера, удалив данные сайта.

2.2. Оплата и доступ

При оплате через PayPal платёж обрабатывает PayPal. Country Matcher не получает полный номер банковской карты или другие полные платёжные реквизиты, которыми пользователь рассчитывается через PayPal.

Для подтверждения покупки Country Matcher может получать и обрабатывать данные, необходимые для проверки транзакции и выдачи доступа, например идентификатор заказа, статус оплаты, сумму, валюту и те сведения о плательщике, которые PayPal предоставляет продавцу в рамках конкретной транзакции.

Для автоматической проверки оплаты и выдачи доступа используется Cloudflare Worker. В браузере сохраняются технические данные доступа, включая токен доступа и, при необходимости, идентификатор незавершённого заказа.

При ручной оплате или обращении в поддержку могут дополнительно обрабатываться сведения, которые пользователь добровольно передаст для поиска платежа и восстановления доступа.

2.3. Email-подписка

Если пользователь добровольно подписывается на обновления Country Matcher, обрабатывается его email-адрес и информация, связанная с подпиской и подтверждением согласия.

Цель подписки — отправлять сообщения о новых странах, обновлениях продукта, важных новостях и предложениях Country Matcher. Подписка не является условием покупки или использования Country Matcher.

Для ведения списка подписчиков и отправки писем используется Brevo. Email и данные подписки передаются Brevo для этой цели. Пользователь может отписаться в любой момент по ссылке в письме или написав на countrymatchersupport@gmail.com.

Если используется double opt-in, адрес становится активным подписчиком только после подтверждения подписки по ссылке из письма.

2.4. Аналитика лендинга

На лендинге используется Microsoft Clarity для анализа взаимодействия пользователей со страницей и качества пользовательского опыта.

Country Matcher не изменяет текущую техническую конфигурацию Clarity в рамках этой интеграции legal-документов и email-подписки.

Microsoft Clarity может обрабатывать технические и поведенческие данные в соответствии со своей собственной конфигурацией и правилами Microsoft.

2.5. Технические данные сайта

При загрузке сайта хостинг и инфраструктурные провайдеры могут автоматически обрабатывать стандартные технические данные веб-запроса, например IP-адрес, тип браузера, дату и время запроса и технические журналы, необходимые для доставки, безопасности и стабильной работы сайта.

3. Для чего используются данные

Данные используются в объёме, необходимом для следующих целей:

  • предоставить работу анкеты и сохранить черновик по выбору пользователя;
  • рассчитать результат Country Matcher в браузере;
  • принять и подтвердить оплату;
  • выдать, проверить или восстановить оплаченный доступ;
  • отвечать на обращения пользователей;
  • отправлять добровольно запрошенные email-обновления;
  • анализировать использование и работу лендинга;
  • обеспечивать безопасность и предотвращать злоупотребления;
  • выполнять обязательные требования применимого законодательства.

4. Правовые основания

В зависимости от применимого законодательства обработка может основываться на:

  • необходимости исполнить договор с пользователем;
  • согласии пользователя — для добровольной email-рассылки;
  • законных интересах оператора — например, обеспечении безопасности, когда такое основание допускается законом;
  • выполнении юридических обязанностей оператора.

Если обработка основана на согласии, пользователь может отозвать его на будущее.

5. Кому могут передаваться данные

В зависимости от используемой функции данные могут обрабатываться следующими категориями получателей:

  • PayPal — проведение оплаты;
  • Cloudflare — техническая инфраструктура проверки оплаты и выдачи доступа;
  • Brevo — список подписчиков и email-рассылки;
  • Microsoft Clarity / Microsoft — аналитика лендинга;
  • GitHub Pages / GitHub — хостинг публичной части сайта;
  • профессиональные консультанты, подрядчики или государственные органы — только когда это необходимо и законно.

Некоторые поставщики самостоятельно определяют цели и способы части обработки и применяют собственные privacy terms. Для других операций они могут действовать как обработчики данных от имени Country Matcher.

6. Международная передача данных

Поставщики Country Matcher могут иметь инфраструктуру и юридические лица в разных странах. Поэтому персональные данные, не относящиеся к локально сохранённым ответам анкеты, могут обрабатываться за пределами страны пользователя. Если применимое право требует специальных гарантий для международной передачи, оператор использует предусмотренные законом механизмы в той мере, в которой они применимы.

7. Срок хранения

  • Ответы анкеты и черновик хранятся в браузере пользователя до удаления пользователем, очистки данных сайта или изменения механизма хранения.
  • Данные доступа хранятся в браузере в объёме, необходимом для работы приобретённого доступа.
  • Данные о транзакциях могут храниться столько, сколько необходимо для подтверждения покупки, поддержки, бухгалтерских/налоговых обязанностей, предотвращения мошенничества и защиты законных требований.
  • Email хранится в списке подписчиков до отписки или иного законного основания для удаления/ограничения обработки.
  • Аналитические данные хранятся по правилам и настройкам соответствующего провайдера и оператора.

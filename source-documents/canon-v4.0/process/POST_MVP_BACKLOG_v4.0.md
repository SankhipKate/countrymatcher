# Post-MVP backlog после Испании

Версия: 4.0

Это осознанно отложенные пункты. Они не должны блокировать добавление новых стран после прохождения MVP-регрессий Испании.

- Разобрать P1/P2 semantic diff и принять решения по оставшимся потерянным/ослабленным нормам.
- Восстановить полный контракт сопоставимой городской корзины и медианы страны.
- Добавить явные состояния покрытия городских компонентов, если это понадобится для устойчивого сравнения стран.
- Определить нормализацию смешанных валют и периодов для cost-of-living.
- Вернуть/пересмотреть визуальные требования карточек и мобильного интерфейса.
- Улучшить нормализованную сортировку маршрутов без зависимости от числа requirements.
- Структурировать сниженные финансовые пороги с условиями применимости (например EU Blue Card), когда движок сможет определить применимость по профилю либо показать альтернативы структурированно.
- Дополнить официальные processing times там, где это улучшает сортировку, но не меняет статус.
- Довести городские населения, size_basis и необязательные practical-блоки.
- Расширить налоговую модель только после появления сопоставимого сценария между странами.
